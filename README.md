# QTMusicplayer demo

### 项目简介
这是一个基于 QT 开发的音乐播放器演示项目。

### 主要功能
- **本地音乐扫描**：支持扫描文件夹并自动识别 `.mp3`, `.wav`, `.flac` 格式文件。
- **数据库持久化**：使用 SQLite (`music_config.db`) 记录播放列表、最后播放状态及播放模式，下次启动自动恢复。
- **智能播放控制**：
  - 支持 **顺序循环**、**单曲循环**、**随机播放** 三种模式。
  - 具备播放/暂停、上一曲/下一曲、进度条拖拽跳进度功能。
- **音量管理**：实时音量调节及一键静音功能。
- **歌词同步显示**：自动关联同名 `.lrc` 文件，实现歌词滚动同步。
- **可视化界面**：
  - **专辑封面**：优先读取音频内嵌封面，若无则自动寻找目录下 `cover.jpg` 或 `folder.jpg`。
  - **双视图切换**：通过 `QStackedWidget` 实现在播放列表与歌词/封面页面的平滑切换

### 运行环境
-**开发框架**：Qt 6.x (C++)
- **多媒体模块**：`QMediaPlayer`, `QAudioOutput`
- **数据库**：Qt SQL (SQLite 驱动)
- **界面设计**：Qt Widgets + UI Designer

### 如何使用
1. 下载本项目代码。
2. 打开你的音乐资源文件
3. 编译并运行。
